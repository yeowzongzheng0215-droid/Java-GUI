# CineStream image assets

你可以直接替换以下图片，不需要修改页面代码：

| 用途 | 文件 | 建议尺寸 |
|---|---|---:|
| 首页大型横幅 | `banner/cinema-hero.png` | 1600 × 560 |
| 登录与注册页视觉图 | `banner/auth-cinema.png` | 700 × 820 |
| The Wandering Earth 3 海报 | `posters/wandering-earth-3.png` | 600 × 800 |
| Zootopia 2 海报 | `posters/zootopia-2.png` | 600 × 800 |
| Avengers 海报 | `posters/avengers-final-chapter.png` | 600 × 800 |
| 缺图时的通用海报 | `posters/placeholder-poster.png` | 600 × 800 |

支持 JavaFX `Image` 能读取的 PNG/JPG。若改用 `.jpg`，也要同步修改 `Model/MovieCatalog.java` 或页面中的资源路径。
